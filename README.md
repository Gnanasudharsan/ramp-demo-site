# Harbor Town Council (demo site)

A fictional town-council website with **deliberately seeded accessibility barriers**. It is the
target for the end-to-end demo of [Ramp](https://github.com/Gnanasudharsan/ramp-accessibility-agent):
Ramp audits the live site, proposes source fixes, verifies them, and opens a pull request here
only after a human approves the exact diff.

Do not use this site as an example of good practice.
